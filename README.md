## About Me

I'm a Software Engineering student who enjoys turning ideas into working, secure software. I build with the **MERN stack**, and I'm steadily working my way into **cybersecurity** — network security, secure coding, and ethical hacking fundamentals.

Here's why I approach it this way:

- I'd rather understand *how* something breaks than just memorize *how* to build it
- Security shouldn't be an afterthought bolted onto a finished app — it should shape how I write code from the start
- AI tools are part of my workflow now, so I'm learning to use them responsibly *and* securely, not just quickly

I'm still early in this journey, and this profile will keep evolving as I learn. Suggestions are always welcome — feel free to reach out.

## Currently Learning

This is where I'm putting my focus right now — the fundamentals I'm building before going deeper into offensive/defensive security work.

### Security Fundamentals

- Networking basics — TCP/IP, DNS, HTTP(S), how traffic actually moves
- Linux & the command line — comfortable enough to not panic in a terminal
- Secure coding practices — input validation, auth, avoiding the OWASP Top 10 classics
- Reading and using tools like Wireshark to actually *see* what's happening on a network

### How I Learn

*A quick look at how I turn "I don't know this" into "I can build/break this."*

1. Pick a concept (e.g. SQL injection) and understand it conceptually first
2. Set up a safe lab environment to test it hands-on
   ```bash
   # example: spinning up a local vulnerable app for practice
   git clone https://github.com/<practice-lab-repo>
   ```
3. Break something on purpose, then figure out *why* it broke
4. Fix it properly, and note the pattern for next time
5. Apply the same instinct to my own MERN projects going forward
